# PakAssist frontend

The completed React/TypeScript/Vite app. See ../README.md for setup, API contracts and tests.

Run npm.cmd ci and npm.cmd run dev from this folder. Build with npm.cmd run build. Backend: http://127.0.0.1:8001; frontend: http://localhost:5173.

The existing English/Urdu design is preserved. Microphone input and uploads use the same conversation. Provider API keys belong only in the backend .env.
